# Claude Secure Network

Проект изолированной сетевой среды для Claude на Android. **На текущем этапе это документация, а не готовое приложение или работающее VPN-решение.**

## Цель

Обеспечить для Claude один заранее выбранный VPN-выход, отсутствие автоматической смены локации и режим **fail closed**: при недоступности защищённого маршрута приложение не должно подключаться к интернету напрямую. Другие приложения телефона должны продолжать работать независимо, насколько позволяет Android.

**Важное ограничение:** сетевая изоляция не гарантирует отсутствия блокировок и не меняет правила Anthropic для неподдерживаемых регионов, в том числе России. Проект не предусматривает подмену личности, документов или идентификаторов устройства.

## Первый запуск

1. Прочитать [AGENTS.md](AGENTS.md), [PROJECT.md](PROJECT.md) и [ТЗ](docs/TECHNICAL_SPECIFICATION.md).
2. Начать с [безопасного аудита реального устройства](docs/DEVICE_AUDIT.md): выполнить `scripts/device_audit.sh` из Termux с Shizuku/rish. Отчёт сохранить локально и не коммитить в публичный репозиторий.
3. Зафиксировать результат аудита и только после этого выбрать окончательную схему изоляции. Нельзя обещать отдельный Always-on/Lockdown без проверки.
4. Для первой работающей версии реализовать один сквозной сценарий: Claude имеет сеть при активном VPN и гарантированно теряет её при его отключении.
5. Подтвердить это наблюдаемыми сетевыми проверками и негативными сценариями. Непроверенные тесты помечать `NOT RUN`.

## Безопасность

Не коммитить приватные ключи WireGuard, `.conf` с секретами, токены Claude, экспортированные cookies, персональные данные и диагностические логи с чувствительными сведениями. См. [.gitignore](.gitignore).

Никаких разрешений на публикацию ключей, автоматическое изменение настроек телефона или выпуск программного продукта эта документация не предоставляет.
